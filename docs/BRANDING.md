# TauntBuddy · Branding

Dark Neon / Glassmorphism, with a judgemental hamster as the face of the app.

## Palette

| Token | Hex | Used for |
| --- | --- | --- |
| Canvas | `#0C0B10` | App background, splash, store art |
| Canvas (alt) | `#121212` | Light-on-dark fallback backgrounds |
| Surface | `#14121B` | Glass cards, sheets, nav rail |
| Primary | `#9D4EDD` | Buttons, sliders, active nav |
| Primary deep | `#8A2BE2` | Gradients beside Primary |
| Glow | `#B388FF` | Neon halos, focus rings, mascot halo |
| Magenta | `#F72585` | Streaks, brand gradient tail, taunt severity 3 |
| Cyan | `#4CC9F0` | Analytics accents, sync affordances |
| Mint | `#3DDC97` | Success, completion, gentle taunts |
| Amber | `#FFB703` | Warnings, PRO, streak flames |
| Text | `#F6F4FF` | Headlines (bold, high contrast) |
| Muted | `#9A95AD` | Subtitles and captions |

Rules of thumb:

- Headlines are **bold white**, never tinted; subtext stays muted grey.
- Accents always carry a **soft glow** (`Glow` at 10–35% behind the element).
- Cards are **heavily rounded** (radius 18–28) with a 1 px subtle border
  (`glassBorder`) and a translucent fill (`glassFill`) — never a heavy shadow.
- The brand gradient runs `#B388FF → #F72585` (used by `GradientText`).

Light mode mirrors the same hues with a near-white canvas; it is a first-class
theme, not an inverted hack.

## Mascot

All in-app mascot art is drawn in code by
`lib/core/widgets/hamster_mascot.dart` (a `CustomPainter`), so the app ships with
zero mascot image files and the hamster scales to any resolution.

`MascotPose` is the animation contract:

| Pose | Personality | Where it shows |
| --- | --- | --- |
| `idle` | Blinking, breathing | Splash, drawer header, profile |
| `focus` | Steady, determined eyes | Ekagra + Dhyan timers |
| `judging` | Squint + raised brow | Dashboard, Taunt Vault |
| `celebrate` | Bounce + sparkle eyes | Goal/badge completion |
| `sleepy` | Half-closed eyes | Late-night taunt idle state |
| `shield` | Stern, KAVACH visor | KAVACH screen |
| `thinking` | Looking up, paw to chin | Planner / sync states |

The launcher icon and PWA icons are the same mark as a flat bitmap, generated by
`tools/generate_branding_assets.dart`:

```bash
dart run tools/generate_branding_assets.dart
```

That script is dependency-free (hand-rolled rasteriser + PNG encoder) so it also
works in CI without extra packages.

## Asset contract

| Path | Size | Purpose |
| --- | --- | --- |
| `android/.../mipmap-*/ic_launcher.png` | 48–192 | Launcher icon |
| `android/.../mipmap-*/ic_launcher_round.png` | 48–192 | Round launcher icon |
| `android/.../mipmap-*/ic_launcher_foreground.png` | 108–432 | Adaptive foreground (safe zone respected) |
| `android/.../mipmap-*/ic_launcher_monochrome.png` | 108–432 | Android 13+ themed icons |
| `web/favicon.png` | 64 | Browser tab |
| `web/icons/Icon-192.png`, `Icon-512.png` | 192, 512 | PWA `any` |
| `web/icons/Icon-maskable-192.png`, `Icon-maskable-512.png` | 192, 512 | PWA `maskable` |
| `assets/branding/icon.png` | 512 | In-app marketing / share cards |
| `assets/branding/icon-maskable.png` | 512 | Full-bleed variant |
| `assets/branding/ic_launcher_foreground.png` | 432 | Reuse in docs/site |

Adaptive icons are declared in
`android/app/src/main/res/mipmap-anydpi-v26/ic_launcher.xml` with
`@color/ic_launcher_background` (`#0C0B10`); the Android 12 splash uses
`@mipmap/ic_launcher_foreground` through `values-v31/styles.xml`.

## Typography

No fonts are bundled — the app uses the platform default (`Roboto` on Android,
`San Francisco` on Apple platforms, `Segoe UI` on Windows). Headlines run at
`FontWeight.w800` with `letterSpacing: -0.6`, body copy at `w400–w600`. The app
clamps the platform text scale to **0.9–1.25** so accessibility settings work
without breaking the glass layouts.

## Voice & tone

The mascot is a Hinglish study buddy, not an insult comic:

- Taunt intensity is user-controlled (Polite / Judgemental / Ruthless) and the
  engine is capped at severity 3 of 3.
- Wellbeing triggers (`comeback`, `wellbeing`) are always gentle.
- Taunt copy lives in `assets/data/taunts.json`, is validated in CI, and is
  fetched at runtime from
  `https://raw.githubusercontent.com/dastaanenajdik/Tauntbuddy/main/assets/data/taunts.json`.

## Regenerating after a palette change

1. Update this file and `lib/core/theme/app_tokens.dart` together.
2. Update the `_Rgb` constants in `tools/generate_branding_assets.dart`.
3. Run the generator (Android icons, web icons and `assets/branding/` all move).
4. `flutter test` + the CI `web` job re-validate the manifest icons.
